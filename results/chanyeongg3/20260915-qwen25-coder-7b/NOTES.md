# 팀 해석 (사람이 작성)

자동 수치·케이스별 증거: [REPORT.md](REPORT.md). 아래 초안은 실행 산출물(results.jsonl, pytest 로그, raw 응답)과 공개 라이선스 원문을 근거로 Claude Code가 정리했으며, 커밋 전 참가자(chanyeongg3)가 검토·확정합니다.

- 모델 카드·라이선스 URL 확인 및 사용 조건 검증: **Apache License 2.0** (Copyright 2024 Alibaba Cloud). 원문은 https://ollama.com/library/qwen2.5-coder 의 라이선스 블롭에서 확인. 복제·수정·재배포·상업적 사용이 허용되며, 배포 시 라이선스 사본 첨부와 변경 파일 표시 의무가 있음. 본 실험(내부 비교 평가)과 이후 코딩 에이전트 활용 목적 모두에 라이선스상 제약 없음.
- 장치 및 동일 PC 여부: 개인 노트북 단독 실행. Windows 11 / RAM 33.8GB / **NVIDIA GeForce RTX 5060 Laptop GPU 8,151 MiB** / 드라이버 592.01 (manifest.json의 `environment.nvidia_gpus` 기록). 팀 공통 평가 PC가 아니므로 **탐색 실험으로 분류**하고, 속도·VRAM 수치를 다른 장비의 결과와 모델 우열로 직접 비교하지 않는다. manifest의 `device_label` 값 "rtx5070-8gb-local"은 실행 시 잘못 입력된 문자열이며, 정확한 장비 정보는 `environment.nvidia_gpus` 기록이 기준이다.
- 발견 1 (실패, B01 금액 반올림, 2회 모두 test_failure): 근거 `model-1/B01-r1.solution.py`, `model-1/B01-r1.pytest.log`. 모델이 **항목별로 HALF_UP 반올림하지 않고 전체 합계를 한 번만 반올림**했다(`sum(...)` 후 `quantize`). 그 결과 `AssertionError: assert '0.01' == '0.02'`로 실패. 공개 테스트는 4개 모두 통과했으나 평가 테스트는 6개 중 3개 실패로, 공개 테스트만으로는 드러나지 않는 요구사항을 놓치는 전형적인 사례다.
- 발견 2 (성공, B02·B04·B06, 각 2회 모두 solved): 근거 `model-1/B04-r1.pytest.log` 등. 페이지네이션(B02)·시간 범위(B04)·사용자별 캐시(B06)는 공개/평가 테스트를 모두 통과했다(예: B04 공개 4/4, 평가 6/6). 반면 Decimal 반올림(B01)·멱등성(B05)·부분 업데이트(B07)·재시도(B08)·권한(B09)·원자성(B10)처럼 **상태 관리와 예외 경로가 얽힌 문제는 10문제 중 7문제에서 2회 모두 실패**했다. 응답 형식 오류·타임아웃·호출 실패는 0건이었고 20회 모두 `done_reason=stop`으로 정상 종료했다.
- 실행 위험 확인: 생성 코드는 현재 사용자 권한으로 파일시스템과 네트워크에 접근합니다. 임시 디렉터리, Python -I, 시간 제한은 보안 격리가 아닙니다.
- 최종 판단 및 한계: 계획 20회 중 **6회 해결(30%)**, 두 번 모두 해결한 문제 3/10. 같은 PC·같은 설정(num_ctx 8192, num_predict 2048, temperature 0.2, seed 42/43)에서 실행한 deepseek-coder:6.7b-instruct(2/20)보다 정확도·속도(66.2 vs 28.2 tokens/s)·VRAM(4,756 vs 5,943 MiB) 모두 앞선다. 다만 **10문제 × 2회는 전체 개발 능력의 대표 표본이 아니므로 통계적 우위를 선언하지 않는다.** 두 후보 모두 절대 정확도가 낮아(30%·10%) 실무 도입 가능 판정이 아니며, 어디까지나 **상대적으로 나은 로컬 후보**라는 의미다. 단일 장비·단일 참가자 실행이라는 점도 한계다.
- API 키·개인정보·원문 로그 공개 전 점검: 결과 폴더 전체를 스캔한 결과 **API 키·토큰·자격증명 패턴은 탐지되지 않았다.** 프롬프트에는 공개 벤치마크 코드만 포함된다. 다만 `model-1/show.raw.json`의 Modelfile 필드에 `C:\Users\<Windows 사용자명>\.ollama\models\blobs\...` 형태의 절대 경로가, 일부 pytest 로그 traceback에 임시 디렉터리 절대 경로가 남아 있어 **Windows 사용자명이 노출된다.** 저장소가 Private인 동안은 팀 내부 공유 범위이므로 그대로 두되, 공개 전환 시에는 마스킹 여부를 팀에서 결정해야 한다.
