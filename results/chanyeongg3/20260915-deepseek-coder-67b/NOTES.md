# 팀 해석 (사람이 작성)

자동 수치·케이스별 증거: [REPORT.md](REPORT.md). 아래 초안은 실행 산출물(results.jsonl, pytest 로그, raw 응답)과 공개 라이선스 원문을 근거로 Claude Code가 정리했으며, 커밋 전 참가자(chanyeongg3)가 검토·확정합니다.

- 모델 카드·라이선스 URL 확인 및 사용 조건 검증: **DeepSeek Model License** (모델 가중치), 코드 저장소는 **MIT License**. 근거는 모델 카드 https://huggingface.co/deepseek-ai/deepseek-coder-6.7b-instruct 이며 **상업적 사용을 허용한다고 명시**되어 있다. Ollama 라이브러리 페이지에는 라이선스 원문이 게시되어 있지 않아 모델 카드를 출처로 사용했다. 세부 사용 제한은 저장소의 `LICENSE-MODEL` 파일에 있으므로, 실서비스 도입을 검토할 경우 해당 원문을 추가로 확인해야 한다(이번 내부 비교 평가 용도에는 제약 없음).
- 장치 및 동일 PC 여부: 개인 노트북 단독 실행. Windows 11 / RAM 33.8GB / **NVIDIA GeForce RTX 5060 Laptop GPU 8,151 MiB** / 드라이버 592.01 (manifest.json의 `environment.nvidia_gpus` 기록). qwen2.5-coder:7b-instruct 실행과 **동일 PC·동일 설정**이며 모델은 순차 실행 후 언로드했다. 팀 공통 평가 PC가 아니므로 **탐색 실험으로 분류**한다. manifest의 `device_label` 값 "rtx5070-8gb-local"은 실행 시 잘못 입력된 문자열이며, 정확한 장비 정보는 `environment.nvidia_gpus` 기록이 기준이다.
- 발견 1 (실패, B01 금액 반올림, 2회 모두 test_failure): 근거 `model-1/B01-r1.solution.py`, `model-1/B01-r1.pytest.log`. 생성된 코드가 **표현식 중간에서 끊겨 문법 오류**가 났다(`rounding=ROUND_HALF`에서 종료 → `SyntaxError: '(' was never closed`). 그 결과 test_public.py·test_hidden.py **둘 다 수집 실패해 테스트가 한 개도 실행되지 않았다**(test_count 0, collection_errors 2건). 출력 한도 때문이 아니라는 점이 중요한데, `done_reason=stop`이고 eval_count는 109토큰으로 num_predict(2048)에 한참 못 미쳤다. 즉 설정 문제가 아니라 모델이 스스로 불완전한 코드를 내놓고 종료한 생성 안정성 문제다.
- 발견 2 (실패, B02 페이지네이션, 2회 모두 test_failure): 근거 `model-1/B02-r1.solution.py`. 로직은 대체로 맞았으나 반환 딕셔너리의 키를 `"page_size"`가 아니라 **`"pageage_size"`로 오타**를 냈다. 공개 4개 중 2개, 평가 6개 중 4개가 실패했다. 같은 문제를 qwen2.5-coder는 2회 모두 해결했으므로, 문제 난이도보다 **생성 품질의 안정성 차이**를 보여주는 대비 사례다. 한편 사용자별 캐시(B06)는 2회 모두 공개 3/3·평가 7/7로 완전히 통과했다.
- 실행 위험 확인: 생성 코드는 현재 사용자 권한으로 파일시스템과 네트워크에 접근합니다. 임시 디렉터리, Python -I, 시간 제한은 보안 격리가 아닙니다.
- 최종 판단 및 한계: 계획 20회 중 **2회 해결(10%)**, 두 번 모두 해결한 문제 1/10(B06). 같은 PC·같은 설정에서 실행한 qwen2.5-coder:7b-instruct(6/20)에 정확도에서 3배 뒤지고, 속도(28.2 vs 66.2 tokens/s)와 VRAM(5,943 vs 4,756 MiB)에서도 불리하다. 다만 양자화가 서로 다르므로(Q4_0 vs Q4_K_M) **이 차이를 모델 자체의 능력 차이로만 설명하지 않는다.** 10문제 × 2회 표본으로 통계적 우위를 선언하지 않으며, 두 후보 모두 절대 정확도가 낮아 실무 도입 가능 판정이 아니다. 호출 실패·타임아웃·형식 오류는 0건으로, 낮은 점수는 인프라 문제가 아니라 응답 품질에서 비롯됐다.
- API 키·개인정보·원문 로그 공개 전 점검: 결과 폴더 전체를 스캔한 결과 **API 키·토큰·자격증명 패턴은 탐지되지 않았다.** 프롬프트에는 공개 벤치마크 코드만 포함된다. 다만 `model-1/show.raw.json`의 Modelfile 필드와 일부 pytest 로그 traceback에 `C:\Users\<Windows 사용자명>\...` 형태의 절대 경로가 남아 **Windows 사용자명이 노출된다.** 저장소가 Private인 동안은 팀 내부 공유 범위이므로 그대로 두되, 공개 전환 시에는 마스킹 여부를 팀에서 결정해야 한다.
