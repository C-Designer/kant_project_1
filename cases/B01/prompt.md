# B01 주문 금액의 줄별 반올림
백엔드 주문 합계 계산의 반올림 오류를 수정하세요.

## 계약
`def invoice_total(lines: list[tuple[str, int]]) -> str`
각 줄은 `(단가, 수량)`입니다. 단가 문자열을 `Decimal`로 정확히 변환하고 수량을 곱한 다음, **각 줄별로** 소수 둘째 자리까지 `ROUND_HALF_UP`으로 반올림합니다. 반올림한 줄 금액을 더해 소수 둘째 자리를 항상 표시하는 문자열을 반환합니다. 총합만 마지막에 반올림하면 안 됩니다. 빈 목록은 `"0.00"`입니다.

## 유효 입력 및 변경
목록 길이는 0~100입니다. 단가는 0~1000000의 음이 아닌 고정소수점 문자열이며 소수부는 최대 6자리입니다. 수량은 bool이 아닌 0~1000의 int입니다. 잘못된 입력 처리는 요구하지 않습니다. 호출 시 Decimal 전역 컨텍스트는 기본값이며 이를 변경하지 마세요. 입력 목록과 튜플을 변경하지 마세요.
