# B06: 사용자별 프로필 캐시 충돌
첫 사용자 조회 후 다른 사용자에게 같은 프로필이 노출되는 버그를 고치세요.

## 계약
- ProfileService(profiles: dict[str, dict[str, str]]) 생성자와 get_profile(user_id: str) -> dict[str, str] 메서드.
- profiles는 사용자 ID에서 프로필로의 매핑. ID는 빈 문자열도 가능한 임의 문자열이며 대소문자를 구분합니다. 프로필 값은 문자열만 있고 프로필 및 전체 매핑은 비어 있어도 됩니다.
- 생성 시 입력 매핑과 각 프로필의 스냅샷을 보관합니다. 원본의 이후 수정은 서비스에 영향을 주지 않습니다.
- 사용자별 캐시를 유지하면서 정확한 프로필을 반환하세요. 조회 순서·반복·다른 인스턴스에 영향받지 않습니다. 내부 캐시 구조나 hit 횟수는 검사하지 않습니다.
- 반환값은 독립 사본. 수정해도 다음 조회나 다른 사용자에게 영향이 없습니다.
- 없는 ID는 KeyError. 실패한 조회는 이후 결과를 바꾸지 않습니다.
- 이외 잘못된 입력 타입은 없습니다.

## 제출
설명 없이 python fenced code block 정확히 하나로 전체 solution.py를 제출하세요. Python 3.12 표준 라이브러리만 사용합니다. 테스트는 pytest를 사용합니다. 네트워크·난수·시계는 금지합니다. 비공개 테스트는 모델에게만 숨기며 저장소 독자는 읽을 수 있습니다. 모든 테스트는 명시된 계약만 검증합니다.
