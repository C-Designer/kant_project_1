## 실행 방식과 한계
현재 Python 인터프리터로 시도별 별도 프로세스와 임시 작업 폴더를 사용합니다. 환경변수 전달을 제한하고, pytest 외부 플러그인 자동 로딩을 끄며, 출력은 최대 2 MiB 분량의 마지막 부분을 보존합니다. 기본 테스트 시간 제한은 30초입니다. POSIX에서는 프로세스 그룹 정리, Windows에서는 최선 노력의 프로세스 트리 종료를 사용합니다.

**보안 격리가 아닙니다.** 생성 코드는 현재 사용자 권한으로 파일·네트워크에 접근할 수 있습니다. 메모리 사용량을 강제로 제한하지 않으며, 의도적으로 분리된 자식 프로세스까지 완전히 정리한다고 보장하지 않습니다. 민감 파일 없는 실습 장비에서 실행하세요. 생성 코드의 악의적인 채점 조작을 방어하는 평가기도 아닙니다.
