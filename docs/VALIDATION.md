# 구현 검증 상태

검증일: 2026-09-15. 환경: macOS, CPython 3.12.14, pytest 8.3.5.

**이것은 문제·채점 코드 검증 결과이지 LLM 성능 실험 결과가 아닙니다.**

## 확인한 항목
- 기준 구현 10개: **100/100 테스트 통과**.
- 버그 초기 구현 10개: 각각 평가용 테스트에 최소 1개 실패. 버그를 실제로 검출함.
- 평가기·개인 실행·보고서 테스트: **172/172 통과**.
- 개인 실행 모의 통합 검증: 참가자 2명에게 같은 run-id를 주어도 별도 폴더 생성, 각 20회와 워밍업 1회 분리, 실제 REPORT.md 생성, NOTES.md 수정 후 재생성 시 보존을 확인함. Ollama와 Docker는 mock이며 실제 모델 성능이 아님.
- report 명령은 모델·Docker 호출 없이 기존 로그만 읽음. 미완료 manifest는 20개 기록이 있더라도 미완료 경고를 유지함.
- Cloud 내보내기: 사전 지정 5문제, 반복 1회, 총 5요청 생성 확인.
- Docker 없는 상태의 본 실험 명령: exit 2로 사전 차단, Ollama 호출이나 결과 폴더 생성 전에 종료함.
- 문제·테스트 교차 검토: 반환 사전의 정확한 키, 개별 None 기본값, 기본 반환값 독립성에 대한 검사를 보강함. 미공개 요구사항을 추가한 것이 아니라 공개 계약의 검증을 보강함.

## 검증 방법과 한계
작성하고 검토한 reference.py 및 starter.py만 각기 별도 임시 디렉터리의 solution.py로 복사해 공개/평가 테스트를 실행했습니다. 이 호스트 검증은 **모델이 생성한 임의 코드를 호스트에서 실행해도 된다는 뜻이 아닙니다.** 팀의 실제 모델 응답은 Docker 평가 경로만 사용합니다.

단위 테스트는 출력 추출·측정치·실패 분모·Docker 명령 옵션·사전 차단·타임아웃 정리·Cloud 반복 수 등을 검증하며 Docker 호출은 mock입니다.

## 아직 검증하지 않은 항목
- 이 Mac에 Docker가 없어 이미지 빌드·실제 컨테이너 실행은 **미검증**.
- Windows 수업 노트북의 설치·파일 마운트·Docker 메모리 제한·Ollama 실행은 **미검증**.
- 이 환경에 PowerShell이 없어 scripts/run-personal.ps1은 코드·CLI 인터페이스 검토만 수행했으며 Windows 실실행은 **미검증**.
- 로컬 모델 2개와 Cloud API의 실제 응답·품질·속도·VRAM·비용은 **미측정**.
- 생성 모델을 이용한 난이도·변별력 실측은 **미실시**. 전부 만점/실패가 되는지는 아직 모름.
- GitHub 팀원 접근은 2026-09-15 사용자가 이미 가능하다고 확인함. 별도 권한 조회·변경은 하지 않았고 저장소 Private와 Notion 기존 공유 범위를 유지함.

## 수업 장비에서 반드시 실행
```powershell
uv sync --frozen
docker build -t kant-harness:1 .
uv run python -m harness verify-cases --out runs/verify-001
```

verification_summary.json의 all_valid=true를 확인한 뒤 모델 본 실험을 시작하세요. 이미지·장비 문제로 검증 실패하면 해결 전 본 실험을 진행하지 않습니다.
